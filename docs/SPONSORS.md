# Support this project

The app is free and will stay free. Donations pay for maintainer time, GPU hours for training and evaluation, CI minutes, code signing, and hosting of model files. No feature is locked behind payment.

## How to give

Links go live once the accounts are set up (see `.github/FUNDING.yml`):

- GitHub Sponsors: _coming soon_
- Open Collective (public ledger): _coming soon_
- One-off tips (Ko-fi, Liberapay or similar): _coming soon_

## Tiers

| Tier | What you get |
| --- | --- |
| Supporter | Our thanks, and your name on this page if you want it |
| Backer | Name in the README sponsor list |
| Team sponsor | Logo in the README and on the release notes |

No tier changes how the software works.

## Transparency

A public ledger of income and spending is published monthly in `docs/ledger/` (starting with the first donation). Sponsors are listed only with their permission.
