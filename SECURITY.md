# Security policy

Because this software handles recordings of private conversations, privacy and security bugs matter a lot.

## Reporting a vulnerability

Please report it privately through GitHub's "Report a vulnerability" button under the repository's Security tab, not as a public issue. Include the version, your operating system, and steps to reproduce.

## What is in scope

- Audio or transcripts leaving the machine without the user turning that on
- Unsafe storage of recordings, transcripts or API keys
- Anything that lets one call or user read another's data
- Installer or update integrity problems

Expect an acknowledgement as soon as the maintainer can, and credit in the fix notes if you want it.
